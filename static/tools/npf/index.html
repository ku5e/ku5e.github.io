Formula Reference

NPF (More Accurate)
t = (35 × N + 30 × p) / (f × cos(δ))
N = aperture   p = pixel pitch (µm)   f = focal length (mm)   δ = declination
Result × 0.75 = critical sharpness. — Michaud, Pujol, Fabre.

Rule of 500
t = 500 / (f × CF)
CF = crop factor   FF: 1.0   APS-C: 1.5–1.6   MFT: 2.0
Simple but ignores aperture, pixel size, and target declination.
